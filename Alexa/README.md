# 🔊 Jaanu – AI Voice Assistant

Jaanu is a Python-based AI Voice Assistant that listens to voice commands and performs different tasks using speech recognition and text-to-speech technology.

The assistant can open websites and Windows applications, search for information, play songs on YouTube, tell the current time and date, and respond to voice commands.

---

## 🚀 Features

- 🎤 Voice Recognition
- 🔊 Text-to-Speech Responses
- 🌐 Open Google
- ▶️ Open YouTube
- 🔎 Search Google
- 🎵 Play Songs on YouTube
- 🕒 Tell Current Time
- 📅 Tell Current Date
- 📚 Search Information
- 🖥️ Open Windows Applications
- 👋 Exit Using Voice Commands
- ❓ Unknown Command Handling

---

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- PyWhatKit
- Wikipedia
- PyAudio

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/RedamJaswanth/BERT-AI-Projects.git
```

### 2. Navigate to the Alexa Project Folder

```bash
cd BERT-AI-Projects/Alexa
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

#### Windows PowerShell

```powershell
.\.venv\Scripts\Activate
```

### 5. Install Required Libraries

```bash
python -m pip install -r requirements.txt
```

### 6. Run the Voice Assistant

```bash
python alexa.py
```

# 🔄 How It Works

```text
🎤 User Voice
      │
      ▼
Speech Recognition
      │
      ▼
Voice Converted to Text
      │
      ▼
Command Processing
      │
      ├── Open Websites
      ├── Open Applications
      ├── Search Information
      ├── Play Music
      ├── Tell Time
      └── Tell Date
      │
      ▼
🔊 Jaanu Voice Response
```
