# BERT Chatbot 🤖

A chatbot built using BERT, Streamlit, and Natural Language Processing.

## Features

- User-friendly chatbot interface
- BERT-based text understanding
- Cosine similarity for finding relevant responses
- Streamlit web interface

## Technologies Used

- Python
- BERT
- Transformers
- PyTorch
- Streamlit
- Scikit-learn

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/RedamJaswanth/BERT-AI-Projects.git
```

### 2. Go to the Project Folder

```bash
cd BERT-AI-Projects
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Run the BERT Chatbot

```bash
python -m streamlit run bert_chatbot.py
```
